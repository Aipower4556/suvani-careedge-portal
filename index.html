Integrate Real Power BI

Paste your real Power BI **Embed Link** below. The portal will save this locally in your browser and connect to your live report instead of the simulated dashboard.

How to get the correct link in Power BI:

For Secure Reports (Requires Login):

  1. Open your report on app.powerbi.com.
  2. Click File → Embed report → Website or portal.
  3. Copy the URL from the field labeled "Here is a link you can use to embed this content" (starts with https://app.powerbi.com/reportEmbed) and paste it above.
  4. Note: A "Sign In" button will appear inside our portal. Once you sign in with your credentials, the report will load securely.

For Public Reports (No Login Required):

  1. Click File → Embed report → Publish to web (public).
  2. Copy the URL from the first box (starts with https://app.powerbi.com/view) and paste it above.
